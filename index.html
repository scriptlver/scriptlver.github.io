Less Stress

O LessStress é um projeto voltado para oferecer apoio psicológico acessível e acolhedor, conectando pacientes e profissionais da área de psicologia em um ambiente digital seguro e intuitivo.

  • Login e autenticação de usuário;
  • Cadastro de paciente e psicólogo;
  • Agendamento de consultas online;
  • Histórico de consultas e anotações;
  • Interface adaptada para desktop e mobile.

Locket

Locket é uma aplicação web inspirada no álbum Locket da Madison Beer.

  • Autenticação com registro e login de usuários;
  • Edição de perfil com bio e foto personalizada;
  • Gerenciamento de músicas favoritas por usuário;
  • Integração com API para consumo e envio de dados;
  • Interface responsiva inspirada no álbum.

OhTroca

O OhTroca é um aplicativo criado para facilitar a troca de brinquedos do McDonald’s. Ele oferece aos usuários uma forma prática, interativa e divertida de completar suas coleções.

  • Marca fictícia para colecionadores de brinquedos;
  • Cadastro e gerenciamento de coleção pessoal;
  • Interface intuitiva para facilitar trocas entre usuários;
  • Chat para negociação direta entre usuários;
  • Sistema de avaliações entre usuários.

Skyerate

Plataforma full stack para avaliações de mídias como filmes, livros, séries, músicas e animes.

  • Cadastro e login com autenticação JWT;
  • CRUD de diferentes tipos de mídia;
  • Sistema de avaliações e favoritos;
  • Perfis personalizados e seguidores;
  • API GraphQL integrada ao React.
